breaking down the below regex:
r"^.+@.+\.edu$"

This regular expression (also known as a regex or regexp) is used to match strings that are 
either empty or match the pattern username@organization.edu. 

Here's how it works:
^: This asserts the start of a line.
.+: This matches one or more of any character (except a newline).
@: This matches the @ symbol.
.+: This matches one or more of any character (except a newline).
\.edu: This matches the .edu domain extension.
$: This asserts the end of a line.

So, this regular expression matches any string that ends with @something.edu, with any 
characters in between. It's used to check if a given string is a valid email address.
